UQP Dashboard 圖表｜第 18 階段：合成資料功能實測包
================================================

【用途】
這是完全離線、純前端的圖表功能示範，供操作驗收使用。
內含 BAR／LINE／PIE 圖表、多張圖表新增、編輯、複製、刪除、畫布位置、
三種預設尺寸、自訂寬高（寬 320～7680、高 240～4320 像素）與全螢幕預覽。
編輯 Width／Height 時可先輸入完整數字，按 Enter 或移出欄位才套用限制。
「顯示圖例」核取方塊與文字會保持同一行。所有數字與標籤均為合成資料。

【Windows 10 / 11 操作】
1. 從 GitHub CI # 本次 SUCCESS 的 Artifacts 下載「uqp-chart-synthetic-lab-NOT-FOR-PRODUCTION-...」。
2. 解壓縮至測試用資料夾，例如 C:\UQP_Chart_Lab（不要解壓至 C:\UQP）。
3. 確認安裝 Node.js v24.22.1（或符合專案相容條件的 Node 24）。
4. 執行 start-chart-lab.bat，瀏覽器開啟 http://127.0.0.1:4174/chart-lab.html。
5. 測試新增／編輯／複製／刪除圖表、不同螢幕、全螢幕。結束時於命令視窗按 Ctrl+C。
若瀏覽器先於伺服器啟動，重新整理一次即可。

【安全範圍】
僅監聽 127.0.0.1:4174。HTTP 回應設定 connect-src 'none'，
不提供 /api、SQL 連接、後端登入、患者資料、任何實際儲存或稽核寫入。
頁面設定只存在目前瀏覽器記憶體中，重新整理或離開即清除。
此包不是正式 UQP 客戶端更新、不是 Migration 928、不是 CHART 上線核准。

【限制】
此處的「來源」只是情境標籤，不會執行 Query；不能驗證正式 Dataset
遮蔽、患者稽核、真實 Dashboard 查詢及播放裝置權限。
上述項目在第 20 階段另行安全驗收；第 19 階段僅做本展示包的操作驗收。
不要用這個 ZIP 覆蓋正式 C:\UQP，也不要把本頁截圖誤認為真實患者資訊。

【技術】
合成資料於 React 中生成；使用 Vite build 建置；
start-chart-lab.bat 透過 Node.js 標準函式庫啟動僅 localhost 的靜態伺服器。
