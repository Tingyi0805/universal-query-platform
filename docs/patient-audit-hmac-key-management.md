# 患者識別碼 HMAC 金鑰管理

新增 `patientIdentityHmac.ts`：使用 HMAC-SHA256 計算 32-byte 識別碼摘要。病歷號及其他患者識別碼不直接寫入稽核表。識別碼正規化時保留前導零，並以來源 scope 隔離不同 HIS 的識別空間。

正式部署時應由安全的環境設定或秘密管理系統提供**至少 32 bytes 的隨機金鑰**，以標準 Base64 格式提供；絕對不可放在 GitHub、SQL Server 稽核表、前端程式碼或 log。

金鑰輪替需要版本化（例如 KeyVersion），保留受控舊金鑰以供歷史稽核查詢，並限制可執行反查的稽核人員。現階段尚未建立金鑰版本管理與正式稽核查詢 API。

**本 PR 僅實作 HMAC 函式及單元測試**，不會自動記錄患者清單；後續必須整合實際查詢回應、欄位驗證、金鑰生命週期及稽核失敗時的阻擋策略。
